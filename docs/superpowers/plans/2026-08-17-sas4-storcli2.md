# SAS4 / StorCLI2 Support Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Read 9600-series (SAS4 / mpi3mr) controllers through StorCLI2, replacing the refusal message with real support — porting techanonymous's implementation onto our current tree.

**Architecture:** `hba_each` gains an optional third function for StorCLI2, selected by `STORCLI_FLAVOR`, which is detected from the tool's own banner rather than its filename. Four new pure `stdin→JSON` parse filters handle StorCLI2's output. The JSON gains a third `backend` value, `storcli2`, and PHP folds it onto the storcli record shape through one normaliser rather than branching per tool.

**Tech Stack:** Bash 5, PHP 8, golden-file tests via `tests/run.sh`, assertion tests via `tests/run_php.sh`, shellcheck in CI.

**Spec:** `docs/superpowers/specs/2026-08-17-sas4-storcli2-design.md`

Then widen `hba_each` to their shape — third argument optional, defaulting to the storcli function, and the `backend` field carrying the flavour:

```bash
hba_each() {
    local storcli_fn="$1" lsiutil_fn="$2" storcli2_fn="${3:-$1}" fn c count body rc
    if use_storcli; then
        count=$(storcli_count)
        if [ "$STORCLI_FLAVOR" = storcli2 ]; then fn="$storcli2_fn"; else fn="$storcli_fn"; fi
        printf '{"backend":"%s","driver":"%s","controllers":[' "${STORCLI_FLAVOR:-storcli}" "$(hba_driver)"
        for c in $(seq 0 $((count - 1))); do
            [ "$c" -gt 0 ] && printf ','
            "$fn" "$c"
        done
        printf ']}'
    else
        body=$("$lsiutil_fn"); rc=$?
        if [ "$rc" -ne 0 ]; then printf '%s' "$body"; return; fi
        printf '{"backend":"lsiutil","driver":"%s","controllers":[%s]}' "$(hba_driver)" "$body"
    fi
}
```

The default on `$3` is what keeps every current two-argument caller working unchanged.

storcli_run() {

pci_addr_to_sysfs_dir() {   # $1 = "dom:bus:dev:fn"
